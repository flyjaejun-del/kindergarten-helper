# 우리 반 하루 도우미

유치원 교사용 웹 앱입니다. 설치 없이 브라우저에서 바로 열립니다.

바로 열기: https://flyjaejun-del.github.io/kindergarten-helper/

## 기능

- 🙋 출석 체크, 🗓️ 오늘 일과표(크게 보여주기), ⏰ 시각 타이머
- 🎯 이름 뽑기, ⭐ 칭찬 스티커
- 📝 관찰 기록(누리과정 5개 영역)과 💌 알림장 만들기
- 🧪 STEAM 놀이: 색 섞기, 소리 탐색, 패턴 놀이

## 개인정보

아이 명단과 기록은 서버로 보내지 않고, 사용하는 기기의 브라우저에만 저장됩니다.
다른 기기로 옮길 때는 설정 탭의 백업 파일 내려받기/불러오기를 사용합니다.
