# 우리 반 하루 도우미

유치원과 초등학교 교사용 웹 앱입니다. 설치 없이 브라우저에서 바로 열립니다.
오른쪽 위 🧸 유치원 / 🎒 초등 버튼으로 학교급을 바꿀 수 있습니다.

바로 열기: https://flyjaejun-del.github.io/kindergarten-helper/

## 기능

- 🙋 출석 체크, 🗓️ 오늘 일과표(크게 보여주기), ⏰ 시각 타이머
- 🎯 이름 뽑기, ⭐ 칭찬 스티커
- 📝 관찰 기록(누리과정 5개 영역)과 💌 알림장 만들기
- 🧪 STEAM 놀이: 색 섞기, 소리 탐색, 패턴 놀이

### 🎒 초등 모드에서 달라지는 점

- 🗓️ 교시별 시간표와 교과 버튼(국어~창의적 체험활동, 1~2학년 통합교과 포함)
- 👥 모둠 편성: 출석한 학생으로 무작위 모둠, 모둠장 정하기, 모둠 점수판
- 🧹 1인 1역: 역할 무작위 배정, 한 칸씩 돌리기, 오늘 완료 표시
- 📝 생활 기록(교과 학습·생활 습관·교우 관계·창의적 체험활동·진로·특기)
- ✏️ 오늘의 소감: 학생이 직접 기분과 소감을 쓰고, 알림장에 함께 넣기
- 🧪 STEAM 탐구: 학년별 규칙 찾기(1~2학년 뛰어 세기, 3학년 이상 수의 규칙), 소리 진동수(Hz) 표시

## 개인정보

아이 명단과 기록은 서버로 보내지 않고, 사용하는 기기의 브라우저에만 저장됩니다.
다른 기기로 옮길 때는 설정 탭의 백업 파일 내려받기/불러오기를 사용합니다.
